# 数据验证

本文介绍如何检查并回放 `replay_zarr.py` 使用的 Zarr 数据。这里先记录数据集检查与机械臂回放流程；后续其他数据相关的验证和操作说明也可以继续放在本文档中。

## 回放流程

`scripts/data/replay_zarr.py` 的主要执行顺序如下：

1. 以只读方式打开 Zarr 数据集，根据 `data/episode` 中连续的 episode 编号划分片段。
2. 检查必需数组、样本数量、位姿维度和数值有效性，并检查动作与位姿变化是否大致一致。
3. 列出可用 episode，等待操作者选择。此时尚未连接机械臂。
4. 选择后连接机械臂；确认回放后，机械臂先回到初始位置，再移动到该 episode 记录的开局位姿。
5. 按顺序发送记录的末端位移动作与夹爪状态。结束、按 `q` 或中断后，可选择复位继续或退出。

检查发现动作和位姿变化不一致时，脚本会给出警告但仍允许选择回放；缺少必需数组、数据为空、数组长度不一致或位姿维度错误时则不能正常回放。`meta/episode_ends` 只用于显示元数据，episode 范围以 `data/episode` 为准。

## 使用方法

在仓库根目录运行：

```powershell
python scripts/data/replay_zarr.py --input datasets/demo.zarr --addr 192.168.31.232
```

可选参数：

- `--input`：Zarr 数据集路径。
- `--addr`：xArm 地址。
- `--hz`：回放频率，默认 `10`。机械臂接口调用耗时可能使实际频率低于设定值。
- `--speed`：机械臂运动速度参数，默认 `100`，有效范围为 `(0, 2000]`。

在 episode 列表中输入序号选择片段，输入 `q` 退出。开始运动前脚本会显示计算出的开局位姿并要求确认。运行前应确认机械臂周围空间、工装和速度设置适合这段轨迹，并确保急停可用。回放期间输入 `q` 会尝试停止机械臂。

## 开局扰动与回放位姿

采集器在每个 episode 开始前复位到固定 Home 位姿，再施加该轮实际使用的固定与随机偏移。实际偏移保存在 `meta/episode_config/episode_XXXXXX` 的 `start_bias` 属性中。

回放时，脚本读取所选 episode 的 `start_bias`，复位到 Home 后直接发送这条偏置移动，再按顺序执行该 episode 的动作和夹爪记录。随机偏移不重新抽取，也不会重复叠加固定偏移。偏置是相对 Home 的六维增量 `[x, y, z, roll, pitch, yaw]`，不是绝对目标位姿。

当前回放要求所选 episode 存在有效的偏置元数据；缺失配置时会提示错误并跳过该 episode，不会使用首帧数据推算或回退到旧的开局移动方式。`data/pos` 仍保存每帧动作执行后的 `goal_pos`，用于数据检查；它不再决定回放前的偏置移动。

## 数据结构要点

每个样本必须包含以下数组，且第一维长度一致：

| 数组 | 含义 | 形状要求 |
| --- | --- | --- |
| `data/episode` | 每个样本所属的 episode 编号 | `(N,)` |
| `data/action` | 末端增量动作 | `(N, 6)` |
| `data/pos` | 动作后的目标位姿 | `(N, 6)` |
| `data/gripper_action` | 夹爪开合记录，`0` 为闭合、`1` 为打开 | `(N, ...)` |

如果数据集包含其他数组，它们也应与样本总数对齐。回放脚本以只读模式打开数据集，不会修复或改写数据。

### Episode 级采集配置

采集器会把每个**成功保存**的 episode 的开局偏置配置写入 Zarr 根目录下的 `meta/episode_config/`。例如：

```text
demo.zarr/
└── meta/
    ├── episode_ends
    └── episode_config/
        ├── episode_000000/
        └── episode_000001/
```

每个 `episode_XXXXXX` 是一个 Zarr group，具体配置保存在该 group 的 attributes 中，而不是逐帧数组：

| Attribute | 含义 |
| --- | --- |
| `episode_index` | episode 的实际编号；目录名补齐为 6 位只是为了便于排序 |
| `start_bias` | 本轮实际应用的开局偏移 `[x, y, z, roll, pitch, yaw]`，包含随机抽样结果 |
| `start_bias_base` | 配置的固定平移偏置 `[x, y, z]` |
| `random_bias_ranges` | 本轮配置的随机偏移范围，例如 `{"x": [-50, 70]}`；未配置的轴不出现 |
| `gripper_always_closed` | 本轮是否启用了夹爪始终闭合模式 |

例如，固定偏置为 `[0, 0, -200]`，X 轴范围为 `[-50, 70]`，本轮抽到 `+35` 时，`start_bias` 会记录 `[35, 0, -200, 0, 0, 0]`，同时 `start_bias_base` 记录 `[0, 0, -200]`，随机范围单独保存在 `random_bias_ranges` 中。

配置只在 episode 数据确认保存后写入；被丢弃的 episode 不会留下配置组。旧数据集或断点续采前已有的 episode 可能没有对应配置组。

这些配置位于 `meta`，不会影响 `data` 中逐帧数组长度，也不会改变当前 LeRobot 转换结果。`replay_zarr.py` 会按 episode 编号读取对应的 `start_bias`，并将其用于复位后的开局偏置移动。
